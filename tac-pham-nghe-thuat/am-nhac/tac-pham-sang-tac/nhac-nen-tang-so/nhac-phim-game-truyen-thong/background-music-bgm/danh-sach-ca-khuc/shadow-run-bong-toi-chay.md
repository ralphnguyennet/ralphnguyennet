# Shadow Run (Bóng tối chạy)

**Shadow Run**\
**Thể loại:** Nhạc phim – Game – Truyền thông (Background Music – BGM)\

**Mood:** Nhịp nhanh, căng thẳng, năng lượng cao, phù hợp cảnh hành động, rượt đuổi, chiến đấu\
